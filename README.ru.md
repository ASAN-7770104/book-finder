# Book Finder

[English](README.md) · **Русский**

Небольшое серверное веб-приложение для **поиска книг** через Open Library API. Для каждого запроса показывает число
результатов, **диаграмму книг по десятилетиям**, самых частых авторов и карточки с обложками. На странице книги есть
описание, **шкалы оценок**, темы и ссылки; страницы авторов и тем показывают их книги.

Учебный индивидуальный проект по *Web Development II*: **Express, Node.js, Axios и EJS**.

## Возможности

- Поиск по всему, названию, автору или теме с сортировкой и страницами
- Диаграмма по десятилетиям, частые авторы, книга с наибольшим числом изданий
- Проверка ввода на сервере, своя страница 404 и общий обработчик ошибок
- Приложение не падает при неверном вводе и сбоях API; кэш на 10 минут и один повтор запроса
- Адаптивная вёрстка и светлая или тёмная тема

## Запуск

Нужен Node.js 18 или новее. Ключ для API не нужен.

```bash
npm install
cp .env.example .env     # в Windows: copy .env.example .env
npm start
```

Откройте <http://localhost:3000>. Тесты: `npm test`.

Маршруты, устройство проекта и описание промежуточных обработчиков смотрите в [английской версии](README.md).
